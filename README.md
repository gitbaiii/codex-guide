# Codex 中文入门手册

一个不依赖构建工具的中文 Codex 介绍网站。

## 内容

- 桌面应用、IDE、CLI 与 Cloud 使用方式
- 四步快速入门
- Java / Spring Boot 提示词场景切换与复制
- 交付验收清单与计数
- 常见问题与官方资料链接
- 响应式布局、键盘焦点与无障碍状态提示

## 预览

直接打开 `index.html` 即可浏览。剪贴板功能在 HTTPS 或 localhost 环境使用；不可用时会选中文字供手动复制。

## GitHub Pages 发布

打开仓库 Settings → Pages，在 Build and deployment 中选择 Deploy from a branch，然后选择 main 与 / (root)，保存。

预期地址：https://gitbaiii.github.io/codex-guide/ （只有在 Pages 配置成功且部署完成后才可访问）

此仓库目前为私有。私有仓库使用 Pages 可能需要 GitHub Pro、Team 或 Enterprise 套餐，请以账户实际设置为准。不要仅为部署而擅自更改仓库可见性。
