05 — GOOD TO KNOW

开始前，你可能还想知道。

Codex 和普通聊天写代码有什么区别？

Codex 面向代码库中的实际开发任务。在所选环境和权限范围内，它可以读取项目、修改文件、运行命令，并根据结果继续推进。你仍需要提供上下文，并检查最终代码与验证结果。

Plus 订阅与 API 是同一套计费吗？

ChatGPT 套餐内的 Codex 使用和 API 计费属于不同使用方式。功能、额度与限制可能调整，请查看账号页面和官方套餐说明，本指南不承诺固定任务次数。

Windows 上怎么开始？

从官方快速开始页面选择桌面应用，登录后选择 Codex 并打开项目。喜欢终端的话，可按 CLI 文档安装。系统支持、依赖与安装命令以官方当前说明为准。

如何让它遵守项目约定？

在仓库 AGENTS.md 中说明构建命令、测试方式、代码约定和重要边界，在任务里补充具体约束。不要写入密码、API 密钥或会话凭据。

结果不符合预期，怎么继续？

提供具体报错、复现步骤和预期结果。例如：“UserServiceTest 仍失败，用户不存在时应返回 404，请根据错误继续修复。”本地撤回或修改代码后，也要说明当前状态。
